# 📊 Student Grade Tracker

A lightweight and user-friendly application designed to help educators and students input, track, and analyze academic performance and GPA calculations.

## 🚀 Features

- **Student Data Management:** Easily add, update, and delete student records.
- **Automated Calculations:** Instantly computes individual assignment averages, final grades, and overall GPA.
- **Performance Analytics:** Visual insights and charts showing grade distributions (e.g., passing vs. failing).
- **Search & Filter:** Quick filtering system to find specific students, classes, or letter grades.

## ⚙️ Installation & Setup

Follow these steps to run the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd student-grade-tracker
   ```

3. **Install dependencies:**
   ```bash
   npm install  # Or pip install -r requirements.txt
   ```

4. **Start the application:**
   ```bash
   npm start    # Or python app.py
   ```
